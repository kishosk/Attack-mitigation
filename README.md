This project presents an attack mitigation framework using DNSFormer and NSGA-II optimization.
A Transformer-based model is implemented to classify benign and malicious DNS traffic using statistical and behavioral features.
The system detects attacks such as DNS tunneling, amplification, and data exfiltration.
Feature normalization and preprocessing techniques are applied to improve model performance.
NSGA-II is integrated to optimize detection accuracy while maintaining network performance metrics.
The model is evaluated using standard metrics including accuracy, precision, recall, F1-score, and confusion matrix.
Some datasets used for training and testing are very large; hence they are not uploaded to this repository.
